The WebRTC-Direct listener now acts as a true ICE-Lite agent: it answers the dialer's STUN connectivity checks but never initiates its own, matching the spec (the publicly-reachable server "acts as an ICE Lite agent") and go-libp2p / rust-libp2p, whose ICE stacks flip a native lite flag. aioice has no local lite mode, so the muxed listener connection's ``check_start`` is replaced with a respond-only version that completes ICE on the controlling dialer's nomination.
